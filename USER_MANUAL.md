# NexusVault User Manual

Welcome to the Anomaly Network. This manual provides everything you need to know to navigate, create, and collaborate within NexusVault.

## 1. Identity & Access
*   **Authentication:** Access the platform via the Neo-Brutalist login portal powered by Clerk.
*   **Sovereignty:** You can manage your identity settings, including profile avatars and account deletion, via the "User Settings" menu.

## 2. Managing Anomalies (Repositories)
*   **Creating a Repository:** Click the "New Anomaly" button on your dashboard. You must provide a unique name and select a visibility tier (Public or Private).
*   **Navigation:** Use the "Breadcrumb" bar to navigate between branches, folders, and files.
*   **The Danger Zone:** Use the Admin Panel to rename branches, add collaborators, or permanently delete the repository.

## 3. Collaboration Tools
*   **Issue Tracker:** Report bugs or suggest features using the Issue panel. We support full Markdown for detailed technical descriptions.
*   **Wiki Engine:** Document your project's lore and technical specifications in the built-in Wiki. The Wiki supports both dark and light viewing modes.
*   **Pull Requests:** Compare branches and merge code changes using the PR panel. All merges undergo an integrity check before being committed to the target branch.

## 4. Design Philosophy
*   **High Contrast:** If the UI appears difficult to read, check your browser's contrast settings. We utilize a "Neo-Brutalist" system designed for maximum clarity.
*   **Shortcuts:** (Future Feature) Standard keyboard shortcuts for navigation (e.g., `G` then `I` for Issues) will be implemented in Phase 2.
