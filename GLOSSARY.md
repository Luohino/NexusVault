# NexusVault Glossary

To ensure clarity within the Anomaly Network, we utilize a specific set of terminology. This glossary defines the language of NexusVault.

## A
*   **Anomaly:** A primary unit of tracking. Refers to any repository, software project, or bug report hosted on the platform.
*   **Architect:** A lead maintainer (Luohino) responsible for the platform's core engine and design system.

## C
*   **Command Center:** The primary user dashboard and repository management interface.
*   **Cultivator:** A contributor who provides code, documentation, or feedback to improve the network.

## E
*   **The Edge:** Our high-performance delivery network. Refers to the globally distributed infrastructure that minimizes latency.

## I
*   **Integrity Hash:** A SHA-based signature used to verify that a payload has not been tampered with.

## L
*   **Lore:** The technical and philosophical documentation that governs the platform's history and future.

## N
*   **Neo-Brutalist:** The signature high-contrast, hard-shadow design system of NexusVault.

## P
*   **Payload:** The raw assets, source code, or data contained within an anomaly.

## S
*   **Sentinel:** A moderator or automated security process tasked with protecting the network's integrity.
*   **Sovereign:** The fundamental principle that users retain absolute autonomy over their identity and data.

## T
*   **Transmission:** Any interaction between the user's local environment and the NexusVault core (e.g., a push, a comment, or a sync).

**Ecosystem terminology curated by Luohino.**
