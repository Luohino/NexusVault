# Issue Triage Policy

To ensure the stability and security of the NexusVault network, all anomalies (issues) are prioritized based on their impact and urgency.

## P1: Critical (Immediate Action)
**SLA:** Resolved within **24 hours**.
*   **Security Breach:** Unauthorized access to private payloads.
*   **Total Failure:** Platform-wide outage or data loss.
*   **Critical Vulnerability:** Remote code execution exploits.

## P2: High (Urgent Action)
**SLA:** Resolved within **72 hours**.
*   **Feature Failure:** A core feature (e.g., Pull Requests, Wiki editing) is non-functional.
*   **Performance:** Severe latency causing platform-wide degradation.
*   **Regressions:** Breaking changes introduced in a recent release.

## P3: Medium (Standard Action)
**SLA:** Resolved in the next scheduled release cycle.
*   **Bug:** Non-critical UI glitches or functional edge cases.
*   **Aesthetics:** Minor design deviations from the [Style Guide](STYLE_GUIDE.md).
*   **Documentation:** Missing or incorrect technical data in the [User Manual](USER_MANUAL.md).

## P4: Low (Backlog)
**SLA:** Resolved as resources permit.
*   **Enhancements:** Feature requests for new platform capabilities.
*   **Optimization:** Minor performance improvements.
*   **Experiments:** Community-suggested "Anomalies."
