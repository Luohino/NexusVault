# Issue Label Guidelines

To maintain clarity in the Anomaly Tracker, we use a standardized set of labels to categorize and identify the nature of all submissions.

## 1. Type Labels
*   `bug`: Something is not working as intended.
*   `enhancement`: A request for a new feature or improvement.
*   `docs`: Changes to documentation or technical lore.
*   `security`: Issues related to vulnerabilities or system integrity.

## 2. Priority Labels
*   `p1-critical`: Immediate action required.
*   `p2-high`: Urgent but not system-wide failure.
*   `p3-medium`: Standard task for the next release.
*   `p4-low`: Backlog or minor improvement.

## 3. Specialized Labels
*   `anomaly`: A primary unit of tracking in the repository.
*   `payload`: Issues related specifically to code storage or transmission.
*   `protocol`: Legal or governance-related discussions.
*   `sentinel-needed`: Requires review from a lead maintainer.
*   `good-first-issue`: Ideal for new cultivators and contributors.

## 4. Status Labels
*   `in-progress`: Work has begun.
*   `blocked`: Waiting on external factors or dependencies.
*   `resolved`: The anomaly has been neutralized.
