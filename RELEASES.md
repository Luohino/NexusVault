# Release History

## v1.0.0 (Genesis Anomaly) — April 25, 2026
**"The Birth of the Network"**

The initial public launch of the NexusVault platform.

### Features
*   **Core Engine:** High-performance repository browsing and file inspection.
*   **Identity:** Complete integration with Clerk for sovereign user management.
*   **Persistence:** PostgreSQL-backed metadata and issue tracking.
*   **Neo-Brutalist UI:** Implementation of the signature high-contrast design system.
*   **Legal Stack:** Launching with a 50+ file governance and security suite.
*   **Wiki & Issues:** Fully operational Markdown-based collaboration tools.

### Improvements
*   Optimized "Silent Refresh" for issue comments to prevent page reloads.
*   Hardened "Danger Zone" with repository deletion confirmation.
*   Standardized hard shadows and borders across all platform components.
