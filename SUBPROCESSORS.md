# Subprocessor List

**Last Updated:** April 25, 2026

To provide the high-performance NexusVault experience, we partner with specialized third-party service providers (Subprocessors). These entities may have access to certain user data to perform specific technical functions.

## 1. Infrastructure & Hosting
*   **Vercel Inc.:** Provides the global edge hosting and CDN for the NexusVault frontend and API.
*   **Amazon Web Services (AWS):** Provides underlying compute and storage infrastructure.

## 2. Authentication & Identity
*   **Clerk Inc.:** Manages the entire user identity lifecycle, including secure login, session management, and password hashing.

## 3. Database & Storage
*   **Supabase Inc.:** Provides the managed PostgreSQL database, storage buckets for assets, and real-time data synchronization.

## 4. Communications
*   **Resend Inc.:** Provides the transactional email infrastructure for system notifications and collaborator invites.

## 5. Security & Analytics
*   **Cloudflare Inc.:** Provides DDoS protection and DNS management for the `nexusvault.dev` domain.

**Data Protection Commitment:** 
NexusVault maintains a [Supply Chain Ethics](SUPPLY_CHAIN_ETHICS.md) policy to ensure all subprocessors meet our rigorous standards for data privacy and security.
