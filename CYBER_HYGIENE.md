# Cyber Hygiene Guidelines

Maintaining the security of the NexusVault anomaly network is a shared responsibility. These guidelines apply to all "Sentinels," "Cultivators," and platform users.

## 1. Authentication Security
*   **MFA Mandatory:** All maintainers must enable Multi-Factor Authentication on their Clerk and GitHub accounts.
*   **Strong Credentials:** Use a unique, complex passphrase of at least 16 characters.
*   **Token Safety:** Never share Personal Access Tokens (PATs) or commit them to source code.

## 2. Infrastructure Safety
*   **Clean Environment:** Ensure your local development machine is free from malware and utilizes a hardened operating system.
*   **VPN Usage:** Use a trusted, encrypted VPN when accessing the NexusVault admin panels from public networks.

## 3. Communication Hygiene
*   **Encryption:** Use end-to-end encrypted channels (Signal, ProtonMail) for discussing "Level 3" platform secrets or vulnerabilities.
*   **Verification:** Always verify the identity of a maintainer before sharing any non-public technical data.

## 4. Reporting Anomalies
If you observe suspicious activity (e.g., unauthorized login attempts, unusual database latency), report it immediately to the [Security Lead](SECURITY.md).
