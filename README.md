# NexusVault

A modern, high-performance developer platform for hosting repositories, browsing code, and collaborating on anomalies. Built with a Neo-Brutalist aesthetic and local-first philosophy.

## Features

- **High-Fidelity Code Browsing**: Seamless repository navigation with real-time updates.
- **Issue Tracking**: A robust, Markdown-powered system for managing anomalies and payloads.
- **Collaborative Environment**: Integrated comments and status management for seamless team synchronization.
- **Neo-Brutalist UI**: A bold, high-contrast design system that prioritizes speed and clarity.

## Run Locally

**Prerequisites:** Node.js

1. **Install dependencies:**
   `npm install`
2. **Set the environment:**
   Create a `.env.local` file and add your credentials (Clerk, Supabase, Gemini API).
3. **Launch the platform:**
   `npm run dev`
