# Data Portability Guide

NexusVault believes in [Sovereign Identity](SOVEREIGN_IDENTITY_CHARTER.md) and data autonomy. This guide explains how you can export your entire "Anomaly Payload" at any time.

## 1. What You Can Export
You have the right to export the following data in machine-readable formats (JSON, Markdown, and raw source files):
*   **Source Code:** All files and history for every repository you own.
*   **Issues:** Your full issue history, including comments and attachments.
*   **Wiki Content:** All wiki pages and their revision history.
*   **Metadata:** Your user profile, collaborator lists, and repository settings.

## 2. Export Methods
*   **Source Code:** Standard `git clone` or "Download as ZIP" via the repository dashboard.
*   **Issues & Wiki:** (Future Feature) A "Full Export" button in your user settings will generate a `.zip` file containing JSON exports of your metadata.
*   **API:** You can use our [API Reference](API_REFERENCE.md) to programmatically extract your data at any time.

## 3. Data Format Standards
*   **Markdown:** Wiki and issue content is provided in standard GFM.
*   **JSON:** Metadata is provided in standard JSON format for easy import into other systems.

## 4. Rights & Assistance
If you encounter any barriers while attempting to export your data, please contact **lutervyn@gmail.com**. We are committed to processing manual data export requests within **15 business days**.
