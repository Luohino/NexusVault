# Internal Audit Charter

This charter defines the scope and process for the regular self-inspections performed by the NexusVault maintainers.

## 1. Audit Scope
We perform quarterly audits of the following areas:
*   **Security:** Reviewing IAM roles, RLS policies, and secret rotation.
*   **Compliance:** Verifying adherence to the [Privacy Policy](PRIVACY.md) and [DPIA](DPIA_POLICY.md).
*   **Ethics:** Reviewing the [Gifts Registry](GIFTS_POLICY.md) and [Whistleblower Reports](WHISTLEBLOWER_POLICY.md).
*   **Engineering:** Auditing the code base for technical debt and [Testing Coverage](TESTING_STANDARDS.md).

## 2. Process
1.  **Identification:** Select the audit focus area.
2.  **Inspection:** Review the logs, code, and documentation.
3.  **Findings:** Document any "Anomalies" or deviations from the platform standards.
4.  **Remediation:** Assign P1-P4 priorities to fix the findings.

## 3. Transparency
A summary of audit findings (excluding sensitive security data) is included in the [Transparency Report](TRANSPARENCY_REPORT.md).
