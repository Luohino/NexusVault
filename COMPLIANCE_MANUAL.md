# Compliance Management Manual

**Master Governance Document**

This manual provides a consolidated index and guide for the 100+ files that govern the NexusVault network. It is the primary reference for Sentinels and maintainers.

## 1. Using the Governance Stack
NexusVault operates on a "Layered Integrity" model:
*   **Layer 1 (The Soul):** Manifesto, Roadmap, Architecture.
*   **Layer 2 (The Law):** License, Terms, Privacy, SCCs.
*   **Layer 3 (The Shield):** Security, VDP, Playbooks, DRP.
*   **Layer 4 (The Ethics):** ESG, Human Rights, Anti-Corruption.

## 2. Mandatory Compliance Checks
Before any major platform release, maintainers must verify:
- [ ] [DPIA](DPIA_POLICY.md) has been performed for new data features.
- [ ] [Code Review Checklist](CODE_REVIEW_CHECKLIST.md) is complete.
- [ ] [Privacy by Design](PRIVACY_BY_DESIGN.md) principles are met.

## 3. Maintenance of the Lore
The documentation suite is a living entity. If a feature changes, the [User Manual](USER_MANUAL.md) and [Glossary](GLOSSARY.md) must be updated immediately.
